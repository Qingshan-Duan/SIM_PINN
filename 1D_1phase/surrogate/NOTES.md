# surrogate 实验笔记：数据驱动代理 + 离散物理损失正则（Family 2）

> 分支 `feat/surrogate`。目标：量化"物理损失作为正则"的价值——在数据稀缺/含噪/外推时，
> 数据 + 物理是否比纯数据更准、更省数据。结论无论好坏都留档。run 产物在 `output/surrogate/`（gitignored）。

## 设计（与讨论逐字对齐）

- **架构 B（自回归）**：`(场ⁿ, q̂ⁿ) → 场ⁿ⁺¹`，场扛历史、每步只喂瞬时井控；残差连接（学增量）。
- **物理损失 = 离散后向欧拉残差**（`physics.py`）：模拟器自己那条三对角方程的残差，无量纲化到 O(1)。
  定流量井 ⇒ 矩阵 A 是常数（只几何），残差对网络输出线性、解析可导，**不用 autograd 二阶导、
  不用高斯**（原生单格井）。在单相里这一项就是**逐格质量守恒**，是全部物理（达西已并入传导率 T、
  边界并入边界格残差、IC 并入 rollout 初始化）。
- **关键一致性**：数据与物理损失**同一个粗 dt**。模拟器输出令离散残差 = 0（实测机器精度 5e-15），
  所以"数据 + 物理"指向**同一个函数**、后期不打架。（对照 PINN 家族：那边物理=连续真解、参考要细化；
  这里物理=离散方程本身、数据要对齐离散化。**对齐谁取决于物理项代表谁。**）
- **三档对比**：纯数据(λ=0) / 数据+物理(λ>0) / 物理-only(无数据损失，只在场状态上施加 BE 残差)。
- **仿射 LSQ 基线**（`baselines.py`）：最小二乘拟合线性算子，数据下限参照。
- **场景**：同 pinn_tv（两端 20 MPa、cell 7 生产井、基准 −1e-4、每步 ±20%、15 步×1 天），唯井改原生单格。
- **验证**：主指标 = 代理 vs 粗模拟器（held-out test 256 条）rollout；teacher-forced 单步 + rollout 整条。

## 数据

`data_gen.py` → `output/surrogate/data/dataset.npz`：train_pool 512 / val 32 / test 256 条 disjoint
调度（不同种子，全带 [0.8,1.2]）。sweep/grid 按前 N 条嵌套取训练子集。含噪实验对训练**压力场**逐元素
加 N(0,σ) 高斯（井控不加噪、测试集干净）。

## 结果

### 阶段 0：纯数据要多少？—— 问题"太简单"
纯数据从 **N=1（15 个转移对）** 就泛化（test R²=0.9994）。根因：1D 单相线性 ⇒ 自回归算子**精确仿射**
`场ⁿ⁺¹ = W·[场ⁿ, q̂, 1]`。每步独立扰动 ⇒ 一条调度的 15 个 q 已铺满 [0.8,1.2]；且**仿射 LSQ（连网络
都不用）在 256 条测试上 rollout 误差 = 机器零**（即便 N=1 欠定，因测试场落在训练场张成的低维子空间里）。
⇒ "干净数据稀缺"在线性问题上**显不出物理价值，是数学必然**。

### 阶段 1：三档 + LSQ，干净 N-grid（R²/max\|err\| MPa，3 种子均值）
| N | 纯数据 | 数据+物理 | 物理-only | 仿射LSQ |
|---|---|---|---|---|
| 2 | 0.9999/0.061 | 0.9999/0.074 | 0.9946/0.268 | 1.0000/— |
| 4 | 1.0000/0.036 | 0.9999/0.048 | 0.9944/0.271 | 1.0000/— |
| 8 | 1.0000/0.035 | 0.9999/0.043 | 0.9947/0.269 | 1.0000/— |
| 16 | 1.0000/0.028 | 0.9999/0.037 | 0.9946/0.270 | 1.0000/— |

→ 干净时**所有档从 N=2 就近乎完美**（线性可辨识，数据本身就够）。物理-only 略逊（max~0.27）——
受 augmented collocation 流形覆盖所限，但也证明 **BE 残差本身即可定解、根本不需要标签**。

### 阶段 2：三档 + LSQ，含噪 σ=0.1 MPa N-grid（R²/max\|err\|）⭐
| N | 纯数据 | 数据+物理 | 物理-only | 仿射LSQ |
|---|---|---|---|---|
| 2 | **0.750/2.20** | 0.9987/0.112 | 0.987/0.326 | 0.9914 |
| 4 | **0.698/2.66** | **0.9996/0.072** | 0.989/0.326 | 0.9981 |
| 8 | **0.694/4.19** | 0.9997/0.047 | 0.990/0.317 | 0.9992 |
| 16 | 0.932/1.21 | 0.9998/0.042 | 0.991/0.313 | 0.9995 |

→ **纯数据 MLP 崩**（过拟合噪声，喂再多含噪数据也救不回，N=8 反而更差）；**数据+物理最好**
（物理把解钉在 PDE 流形上）；**物理-only 免疫噪声**（标签压根没用）。λ-sweep 见 `A_lambda.png`：
λ 越大去噪越彻底，λ*=30 时数据+物理逼近物理-only。

### 阶段 3：外推（窄带 [0.9,1.1] 训练，clean）
纯数据 带内 0.015 / 带外 0.057；数据+物理 0.026 / 0.065；物理-only 0.222 / 0.276。
→ **线性算子天然外推，纯数据带外也只 ~0.06 MPa，物理无增益**（诚实零结果）。物理-only 带外更差
（窄带 collocation 没覆盖外推区——再次印证物理-only 强依赖 collocation 覆盖）。

### 计算代价
纯数据 7.7s / 数据+物理 22.3s / 物理-only 17.3s（GPU，3000 步全批；物理 ×~2–3）。

## 结论（组会汇报要点）

1. **线性 1D 单相里，物理正则"几乎不需要"——这是诚实且重要的边界结论，不是失败。**
   - 干净：算子精确仿射，**数据(甚至一个线性最小二乘)从 N≈2 就解决**，自由外推；
   - 含噪：纯数据 **MLP** 崩，但**低容量线性模型(LSQ)天生抗噪(R²0.99)**——说明 MLP 的崩主要是
     **过参数化过拟合噪声**，物理的去噪本质是"**把过于灵活的 MLP 正则回(线性)真解**"，而这在线性问题上
     一个简单线性模型就免费做到了。
2. **物理-only(无数据)也能解(R²0.99)且免疫标签噪声**——因为 BE 残差就是方程、本身定解；但**强依赖
   on-manifold collocation**(随机离流形场 → 崩)。⇒ 数据的真正作用是"**告诉网络解流形在哪**(锚点/覆盖)"
   与"干净时白送答案/速度摊销"，而非线性问题里的**原始精度**。
3. **物理写得越全、越精确，数据对精度越冗余**——极端即"物理-only = 神经求解器，何不直接跑模拟器"。
   ⇒ **数据真正不可或缺的两个场景**：① 物理**近似/含未知参数**时数据**纠偏/反演**(历史拟合)；
   ② 多次前向(优化/UQ/反演)时代理**摊销加速 + 端到端可导**。
4. **物理正则的大舞台 = 非线性、算子本身难的问题** → 下一步 **1D 两相**（相渗非线性 + 饱和度激波 +
   非均质/扰动渗透率），仿射 LSQ 失效、数据稀缺变真问题，物理填空隙才有分辨度。见 memory
   `project-next-1d-2phase`、`reference-surrogate-physics-value`。
